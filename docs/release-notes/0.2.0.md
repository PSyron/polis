# Polis 0.2.0

Data: 2026-08-06

## Stan wydania

Polis 0.2.0 jest uniwersalną biblioteką Pythona do analizy i minimalnej
korekty polskiego tekstu. Działa w pełni offline po instalacji, bez lokalnego
modelu językowego, procesu Java, serwera aplikacyjnego i dostępu do sieci.

Wspierany runtime obejmuje:

- deterministyczną analizę opartą na 10 aktywnych regułach;
- stabilne, typowane publiczne API analizy, korekty i serializacji JSON;
- zachowaną pełną powierzchnię `polis.evaluation` opisaną w ADR-0023;
- półotwarte zakresy znakowe `[start, end)` względem oryginalnego tekstu;
- konserwatywną politykę korekt, która w razie niepewności nie proponuje zmiany.

Pakiet pozostaje niezależny od systemu operacyjnego. Codzienny rozwój i szybkie
CI odbywają się na macOS, natomiast te same bajty wheel i sdist przechodzą
końcową kontrolę przenośności na macOS, Linuxie i Windowsie. Nie istnieją osobne
implementacje runtime'u dla poszczególnych platform.

## Dystrybucja i prywatność

Wydanie zawiera jeden wheel i sdist z zamkniętą, jawną listą składników.
Instalacja obu artefaktów jest kwalifikowana bez sieci z przypiętego
wheelhouse'u i z aktywną blokadą połączeń. Publikacja wykorzystuje jeden build,
manifest SHA-256 oraz PyPI Trusted Publishing, dzięki czemu do indeksu trafiają
te same sprawdzone bajty.

Analizowany tekst nie opuszcza urządzenia. Domyślny runtime nie pobiera modeli,
korpusów ani innych danych podczas analizy.

## Ograniczenia

- Polis nie wykonuje semantycznego przepisywania, korekty stylu, tonu ani
  intencji autora.
- Lokalny LLM, pełny LanguageTool i badawcze korpusy nie należą do wspieranego
  runtime'u v1.
- Integracje z DOCX, ODT i RTF pozostają odpowiedzialnością zewnętrznych
  adapterów korzystających z publicznego API.
- Niepewne albo zależne od szerokiego kontekstu sugestie pozostają review-only
  lub są pomijane.

## Instalacja

```console
python -m pip install polis-nlp==0.2.0
```

Minimalny przykład:

```python
from polis import Analyzer, AnalyzerConfig

result = Analyzer(AnalyzerConfig()).analyze("Witaj,świecie.")
print(result.to_json())
```

Szczegółowe kontrakty API, pracy offline, zgodności i ograniczeń znajdują się
w dokumentach dołączonych do dystrybucji.
